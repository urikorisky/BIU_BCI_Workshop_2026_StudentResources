# Brain-Computer Interface (BCI) Workshop 2026

Welcome to the student knowledge base and code repository for the **BCI Workshop 2026**.

This site contains all student-facing materials: lecture guides, circuit diagrams, starter code, and hands-on exercises covering the entire arc from basic electricity and microcontrollers to biopotentials, signal filtering, and brain-computer interfacing.

:::tip Getting Started (Required before Sunday 09:00)
Go to **[Getting Started](docs/getting_started.md)** to download **BCI Workshop Hub** (Windows & macOS), review first-launch security prompts, and run your pre-workshop system check.
:::

---

## 🧭 How to Use This Knowledge Base

1. **Online Documentation**: Browse explanations, interactive circuit guides, and step-by-step lab walk-throughs in a clean, searchable format.
2. **Code & Scripts (`/Scripts`)**: All Arduino sketches (`.ino`) and Python scripts (`.py`) for classroom demos and lab exercises live in the **[Scripts folder on GitHub](https://github.com/urikorisky/BIU_BCI_Workshop_2026_StudentResources/tree/main/Scripts)**.
3. **Getting Code onto Your Machine**:
   - **Beginner (Recommended)**: Use **GitHub Desktop** to clone this repository, or download individual lesson folders.
   - **Direct Download**: Download the entire repository as a `.zip` from GitHub anytime.
