# כיול חיישן EDA / GSR: מעבר מקריאות גולמיות למוליכות (μS)

חיישן ה-**ODAX EDA Maker** מודד פעילות אלקטרודרמלית (EDA / GSR) וממיר את השינויים בעור למתח אנלוגי (`VOUT`), שאותו ה-Arduino קורא דרך פין אנלוגי (`0–1023`).

מכיוון שערכי ה-ADC הגולמיים תלויים בהגבר הפנימי של החיישן, כיול קצר בעזרת **נגדים ידועים** מאפשר לתרגם כל קריאה למוליכות פיזיקלית ביחידות של **מיקרוסימנס (μS)**.

---

## 1. למה החיישן ליניארי במוליכות (`G = 1/R`)?

מבפנים, הלוח משתמש ב**מגבר טרנס-אימפדנס (TIA)**: הוא מפעיל מתח ייחוס קבוע ונמוך (`V_bias`) על האלקטרודות, ומודד את הזרם הזורם דרך העור. לפי חוק אוהם:

```text
I = V_bias / R_skin = V_bias * G_skin
```

מכיוון שהמגבר ממיר את הזרם למתח יציאה (`V_out = V_0 + k * G`), **בתחום העבודה התקין של החיישן (בערך `0.1V–3.5V`, לפני רוויה)** מתקיים קשר **ליניארי ישיר** בין המתח הנמדד לבין המוליכות `G` (בסימנס):

- התנגדות גבוהה מאוד (עור יבש / נתק) ← מוליכות `≈ 0 μS` ← מתח נמוך.
- התנגדות נמוכה (הזעה / עוררות סימפתטית) ← מוליכות גבוהה ← מתח גבוה.

---

## 2. כיול מהיר באמצעות נגדים (Resistor Substitution)

כדי למצוא את נוסחת ההמרה המדויקת עבור הלוח שלכם:

### שלב א': בחרו 4–5 נגדים ידועים מהערכה
חשבו את המוליכות של כל נגד במיקרוסימנס (`G_μS = 10^6 / R_Ω`):

| נגד (`R`) | מוליכות (`G = 1/R`) | הערות |
| :--- | :--- | :--- |
| נתק (Open Circuit) | **`0.00 μS`** | אלקטרודות באוויר |
| `1 MΩ` | **`1.00 μS`** | קצה תחתון של עור יבש |
| `470 kΩ` | **`2.13 μS`** | טווח עור מנוחה טיפוסי |
| `220 kΩ` | **`4.55 μS`** | טווח עור מנוחה טיפוסי |
| `100 kΩ` | **`10.00 μS`** | מוליכות בינונית–גבוהה |
| `47 kΩ` | **`21.28 μS`** | קצה עליון של פעילות עור |

### שלב ב': מדדו את קריאות ה-Arduino לכל נגד
1. חברו את חיישן ה-ODAX ל-Arduino (`VIN` ל-`5V`, `GND` ל-`GND`, `VOUT` ל-`A0`).  
   *(בחיבור לגוף אדם — יש להפעיל את המחשב הנייד על סוללה בלבד, ללא מטען מחובר לחשמל.)*
2. חברו כל נגד בתורו **בין שני מוליכי האלקטרודות (`E+` ו-`E-`)**.  
   ⚠️ **אין לחבר אף אחת משתי האלקטרודות ל-`GND`!**
3. רשמו עבור כל נגד את הערך הממוצע ב-Arduino (`ADC` בטווח `0–1023`, או מתח `V = ADC * 5.0 / 1023`).

### שלב ג': התאמת קו ישר (Linear Fit)
שרטטו או התאימו קו ישר בין המדידות:

```text
G_μS = m * V_out + b    (או: G_μS = m_adc * ADC + b)
```

- אפשר לוודא שהליניאריות נשמרת בכך ש-`100 kΩ` (`10 μS`) יושב בערך באמצע הדרך בין נתק (`0 μS`) לבין `47 kΩ` (`21.3 μS`).
- אם מחברים קצר ישיר (`0 Ω`), החיישן נכנס לרוויה (בסביבות `~3.78 V` / `774` ביחידות ADC) — אל תכללו נקודה זו בהתאמת הקו הישר.

---

## 3. טווח ערכים תקין בעור אנושי
במדידה תקינה מהאצבעות או מכף היד, מוליכות העור הבסיסית (Tonic EDA) נעה לרוב בין **`1 μS` ל-`20 μS`**.  
על פי נתוני היצרן של לוח ה-ODAX (`~0.1 V` ב-`1 MΩ` ו-`~1.2 V` ב-`50 kΩ`), קריאה אופיינית של כ-`1.0 V` עד `1.2 V` (כ-`200–250` ב-ADC) מתאימה לכ-**`16–20 μS`** — בדיוק בטווח הפיזיולוגי התקין.
