# מדריך בסיסי: מדידת ECG עם מודול AD8232

מודול ה-**AD8232** הוא מגבר ביולוגי (Analog Front-End) ייעודי למדידת אותות **ECG** (פעילות חשמלית של הלב) בערוץ אחד.

מכיוון שאות ה-ECG על פני העור חלש מאוד (בסדר גודל של **`~1 mV`** בלבד — פחות מצעד בודד ב-ADC של Arduino!), ה-AD8232 מבצע שלושה דברים לפני שהאות מגיע ל-Arduino:
1. **הגברה דיפרנציאלית** (חיסור בין שתי אלקטרודות כדי להנחית רעש רשת של `50 Hz`).
2. **סינון אנלוגי** (Bandpass של כ-`0.5–40 Hz` להסרת סחיפת DC ורעשים בתדר גבוה).
3. **הזזת נקודת האפס (DC Bias):** ממרכז את האות סביב `~1.65 V` (`3.3 V / 2`), כך שתנודות חיוביות ושליליות של הלב נקראות בצורה תקינה בכניסת `0–5 V` של ה-Arduino.

---

## ⚠️ כללי בטיחות חובה (קראו לפני החיבור!)

- **סוללה בלבד:** כאשר אלקטרודות מחוברות לגוף, **חובה לנתק את המחשב הנייד ממטען החשמל** (עבודה על סוללה בלבד).
- **מתח עבודה `3.3V` בלבד:** שבב ה-AD8232 עובד ב-**`3.3V`** (חיבור ל-`5V` עלול להזיק ללוח).

---

## 1. חיבורים ל-Arduino UNO

| פין ב-AD8232 | פין ב-Arduino UNO | תפקיד |
| :--- | :--- | :--- |
| **`3.3V`** | `3.3V` | מתח הזנה (אין לחבר ל-`5V`!) |
| **`GND`** | `GND` | אדמה משותפת |
| **`OUTPUT`** | `A0` | יציאת ה-ECG האנלוגית המוגברת |
| **`LO-`** | `Pin 11` *(אופציונלי)* | זיהוי ניתוק אלקטרודה |
| **`LO+`** | `Pin 10` *(אופציונלי)* | זיהוי ניתוק אלקטרודה |
| **`SDN`** | לא מחובר | Shutdown (השאירו פנוי) |

## 2. מיקום האלקטרודות (3 אלקטרודות)

הכבל מתחבר לשקע ה-3.5 מ"מ בלוח ומתפצל ל-3 מדבקות ECG לפי מקרא הצבעים הבא:

- 🔴 **אדום (`Red` — `LA`):** **חזה שמאל** — מתחת לעצם הבריח השמאלית (מעל קו החזייה).
- 🟡 **צהוב (`Yellow` — `RA`):** **חזה ימין** — מתחת לעצם הבריח הימנית (מעל קו החזייה).
- 🟢 **ירוק (`Green` — `RL` / ייחוס):** **בטן ימין** — בצד ימין של הבטן התחתונה / צלעות תחתונות (מתחת לפס החזייה ומעל קו המכנסיים).

![מיקום אלקטרודות ECG — AD8232 (גבר ואישה, מבט מלפנים)](/img/ad8232_electrode_placement.png)

> **שימו לב לכיוונים (`R` / `L` — תמונת מראה):**  
> האיור מציג אדם העומד **מולכם**. לכן צד **ימין (`R`)** של הגוף (צהוב + ירוק) מופיע בצד **שמאל** של התמונה, וצד **שמאל (`L`)** של הגוף (אדום) מופיע בצד **ימין** של התמונה.  
> בעת חיבור עם חזייה: יש להניח את המדבקות העליונות מעל החזייה ואת המדבקה הירוקה מתחת לפס החזייה (ומעל המכנסיים) על עור יציב ונקי מרצועות או תפרים כדי למנוע רעשי שריר (EMG) ותזוזה.

## 3. קוד Arduino בסיסי (ללא תלות בספריות)

הקוד הבא דוגם בקצב של כ-`250 Hz` (`115200` baud) ומתאים ישירות ל-**Serial Plotter** וגם ל-**`serial_to_lsl.exe`**:

```cpp
const int PIN_ECG = A0;
const int PIN_LO_PLUS = 10;
const int PIN_LO_MINUS = 11;

void setup() {
  Serial.begin(115200);
  pinMode(PIN_LO_PLUS, INPUT);
  pinMode(PIN_LO_MINUS, INPUT);
}

void loop() {
  if (digitalRead(PIN_LO_PLUS) == 1 || digitalRead(PIN_LO_MINUS) == 1) {
    // אלקטרודה מנותקת: מדפיס קו אמצע יציב (או הודעה)
    Serial.println(512);
  } else {
    int ecg = analogRead(PIN_ECG);
    Serial.println(ecg);
  }
  delay(4); // ~250 Hz
}
```

## 4. בדיקה מהירה ופתרון תקלות

1. פתחו את **Tools → Serial Plotter** (ודאו שקצב התקשורת מוגדר ל-`115200`).
2. שבו בשקט בלי להזיז את הידיים — אמורים להופיע קומפלקסים חדים של **QRS** סביב ערך ביניים של כ-`330–350` (כ-`1.65 V`).
3. **רעש של `50 Hz` (קו עבה ומזמזם):** ודאו שהלפטופ מנותק מהמטען ושמדבקות ה-`RL` והזרועות מוצמדות היטב לעור.
