# מפעילים: מנוע סרוו ובקרת PWM

במערכות BCI והנדסה עצבית, מפעילים (Actuators) מאפשרים לאותות עצביים או לטריגרים מתוכנה לבצע שינוי פיזי בעולם האמיתי (למשל ידיים רובוטיות, מחווני משוב או מתגים מכניים).

במעבדה זו נכיר את מנוע ה-**SG90 Micro Servo** ונבין כיצד מיקרו-בקרים מתקשרים זוויות באמצעות **Pulse Width Modulation (PWM)**.

---

## 🛠️ חומרה וחיבורים (SG90 Servo)

| צבע חוט בסרוו | חיבור | פין ב-Arduino | הערות |
| :--- | :--- | :--- | :--- |
| **חום / שחור** | אדמה | `GND` | אדמה משותפת |
| **אדום** | מתח | `5V` | מתח הפעלה תקני 5V |
| **כתום / צהוב** | אות PWM | `Pin 3` | פין יציאה דיגיטלי |

---

## 📜 סקריפטים זמינים

כל הקבצים נמצאים בתיקיית **[`Scripts/`](https://github.com/urikorisky/BIU_BCI_Workshop_2026_StudentResources/tree/main/Scripts)**:

### 1. הדגמת PWM ידנית (`Servo_Manual_PWM_Demo.ino`)
* **מיקום**: `Scripts/Servo_Manual_PWM_Demo/Servo_Manual_PWM_Demo.ino`
* **עיקרון**: מדגים כיצד מנועי סרוו מפרשים אות PWM בתדר ~50 Hz ללא שימוש בספרייה חיצונית:
  - זמן מחזור כולל: **~20 ms** (50 Hz).
  - רוחב הפולס הגבוה (HIGH) מקודד את זווית היעד:
    - **600 µs** ← `0°` (כ-3.0% duty cycle)
    - **1500 µs** ← `90°` (כ-7.5% duty cycle)
    - **2400 µs** ← `180°` (כ-12.0% duty cycle)
* **מה הקוד עושה**: סורק את הסרוו בצורה חלקה על פני כל הטווח על ידי שליחת פולסים ידניים ל-Pin 3 עם השהיות מדויקות במיקרו-שניות.

---

### 2. סריקה עם ספריית Servo (`Servo_Using_Library_Demo.ino`)
* **מיקום**: `Scripts/Servo_Using_Library_Demo/Servo_Using_Library_Demo.ino`
* **עיקרון**: מראה כיצד ספריית `<Servo.h>` הסטנדרטית של Arduino מנהלת פסיקות טיימר ויצירת פולסים מאחורי הקלעים.
* **מה הקוד עושה**: מזיז את הסרוו הלוך ושוב מ-`0°` ל-`180°` באמצעות פקודות `myServo.write(pos)`.

---

### 3. שליטת זווית אינטראקטיבית דרך Serial (`Servo_Using_Library_SerialControl.ino`)
* **מיקום**: `Scripts/Servo_Using_Library_SerialControl/Servo_Using_Library_SerialControl.ino`
* **עיקרון**: היכרות עם תקשורת טורית (`Serial.begin(9600)`), קריאת מספרים מהמחשב והנעת המפעיל בזמן אמת.
* **מה הקוד עושה**:
  1. פתחו את ה-Serial Monitor ב-Arduino IDE על **9600 baud**.
  2. הקלידו זווית יעד בין `0` ל-`180` ולחצו Enter.
  3. הסרוו יסתובב מיד לזווית המבוקשת.
