# סדנת ממשקי מוח-מכונה (BCI Workshop 2026)

ברוכים הבאים למאגר הידע והקוד לסטודנטים של **BCI Workshop 2026**.

באתר זה תמצאו את כל החומרים לסטודנטים: מדריכי התקנה, הסברים, שרטוטי מעגלים, קוד התחלתי ותרגילים מעשיים — מחשמל בסיסי ומיקרו-בקרים ועד מדידת אותות פיזיולוגיים וממשקי מוח-מכונה.

> 🚀 **הכנה לסדנה (חובה לפני יום ראשון 09:00):**  
> עברו לעמוד **[התקנה והכנה לסדנה](docs/getting_started.md)** להורדת **BCI Workshop Hub** (ל-Windows ו-Mac), הוראות אישור ראשוני, ובדיקת המחשב מראש.

---

## 🧭 איך משתמשים במאגר?

1. **תיעוד מקוון (GitBook)**: קריאת הסברים, מדריכי חיווט ומדריכי מעבדה בצורה נוחה ומסודרת.
2. **קוד וסקריפטים (`/Scripts`)**: כל קבצי ה-Arduino (`.ino`) וסקריפטי ה-Python (`.py`) להדגמות ולמעבדות נמצאים בתיקיית `Scripts` במאגר ה-GitHub.
3. **הורדת הקוד למחשב שלכם**:
   - **למתחילים (מומלץ)**: השתמשו ב-**GitHub Desktop** כדי לשכפל (Clone) את המאגר.
   - **הורדה ישירה**: ניתן להוריד את כל המאגר כקובץ `.zip` בכל עת מ-GitHub.
