# Brain-Computer Interface (BCI) Workshop 2026

Welcome to the student knowledge base and code repository for the **BCI Workshop 2026**.

This repository contains all student-facing materials: lecture guides, circuit diagrams, starter code, and hands-on exercises covering the entire arc from basic electricity and microcontrollers to biopotentials, signal filtering, and brain-computer interfacing.

> עברו לעמוד **[התקנה והכנה לסדנה (Getting Started)](docs/getting_started.md)** להורדת **BCI Workshop Hub** (ל-Windows ו-Mac), הוראות אישור ראשוני, ובדיקת המחשב מראש.

## 🧭 How to Use This Knowledge Base

1. **Online Documentation (GitBook)**: Browse explanations, interactive circuit guides, and step-by-step lab walk-throughs in a clean, searchable format.
2. **Code & Scripts (`/Scripts`)**: All Arduino sketches (`.ino`) and Python notebooks (`.ipynb`) for classroom demos and lab exercises live in the `Scripts` folder.
3. **Getting Code onto Your Machine**:
   - **Beginner (Recommended)**: Use **GitHub Desktop** to clone this repository, or download individual lesson folders.
   - **Direct Download**: Download the entire repository as a `.zip` from GitHub anytime.
